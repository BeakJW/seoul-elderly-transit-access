# 가상 정류소 추가에 따른 접근 면적 변화

## 분석 성격

Maximal covering location problem over exact nonoverlapping improvement polygons; binary MILP via SciPy HiGHS. Conditional on finite hypothetical candidates, not an unconstrained site optimum.

**설치 확정안이 아니라 실제 노선 정류소 사이를 이용한 기하학적 가상 시나리오다. 도로·주거지·공원/수역·정차 가능성을 확인하지 못했다. 따라서 결과를 실제 설치효과·수혜 고령자 수·승객 증가 예측으로 제시하지 않는다.**

## 후보 생성

연속 경유순번·정류소 내부ID를 확인하고, 양 끝이 같은 우선후보 동에 있으며 직선 간격이 600~1,200m인 쌍을 사용했다. 중점이 모든 기존 정류소의 300m 범위 밖인 경우만 남겼다. 원본 양 끝 ID의 무순서 쌍으로 중복 제거한 후보는 1개다. 합성 좌표에는 HYP 식별자를 부여했다. 이 거리 기준은 연구상 가정이며 공식 설치기준이 아니다.

## 최적화와 검증

후보별 추가 면적을 1개의 겹치지 않는 영역으로 나눈 뒤 이진 혼합정수선형계획으로 커버 면적을 최대화했다. 최대 1·3·5개, 선택 후보 간 최소 300m를 적용했다. 목적함수와 실제 폴리곤 합집합 면적을 대조했다. “최적”은 이 유한한 후보·제약·면적 목적 내에서만 성립한다. 고령인구 가중 목적함수나 교통망 최적화가 아니다.

## 해석

후보가 1개뿐이어서 최대 1·3·5개 조건에서 모두 같은 1개가 선택되었다. 무작위 참조도 동일 후보를 선택하므로 최적화의 우월성이나 다수 설치의 추가효과를 검증할 수 없다. 후보를 늘리기 위해 조건을 사후 완화하지 않았다.

면적 커버리지 개선폭은 이후 비율−이전 비율(%p), 기존 대비 증가율은 추가 면적/기존 커버 면적×100, 공백 감소율은 추가 면적/기존 미커버 면적×100으로 구분한다. 동별 지표는 dong_before_after.csv에 있다. 여러 후보의 중복 범위는 한 번만 센다. 인접 동의 혜택은 목표 10개 동 내부만 계산한다.

## 정책 활용의 한계

정류소의 표지·시설을 추가하는 것만으로 실제 운행이 생기는 것은 아니다. 운행 제공을 가정했고, 정차·우회·운행시간 변화와 비용·수요를 산출하지 않았다. 현장 적용 전 실제 도로선형, 버스 통행 가능성, 정차 안전·보행 접근·주거지 여부를 확인하여 후보를 다시 구성해야 한다. 현재 가상 후보를 설치 추천 주소로 사용하지 않는다.

무작위 비교는 동일한 후보와 제약 내 200개 유효 조합의 참고값이며 실제 정책효과 검증이나 예측모형 성능평가가 아니다. 머신러닝을 추가한 것으로 표현하지 않는다.
